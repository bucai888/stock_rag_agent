# 基于RAG的A股中短线选股智能分析智能体
> 垂直领域本地RAG项目，Python全链路开发，完全离线本地化部署，可实现自动选股、财报抓取、私有知识库、AI智能解读。
> 项目用于学习RAG+向量数据库+本地大模型落地，仅作技术演示，**不构成任何投资建议**。

## 📖 项目简介
本项目独立搭建一套「量化选股 + 基本面数据采集 + 本地向量知识库RAG + 本地大模型智能分析」的金融垂直智能体。
解决两个痛点：
1. 通用大模型无法拿到实时A股行情，容易产生幻觉，缺乏真实数据支撑；
2. 量化脚本只能输出数字，无法结合基本面做自然语言分析与风险解读。

整套系统使用纯本地组件，**无云端API调用，数据不会外泄**。支持多业务扩展，同一个Chroma向量库可以通过Collection隔离多个业务知识库。

### 系统四层架构
1. **数据采集层**：Akshare，拉取A股行情、财报，执行技术面量化选股；
2. **文档治理层**：自动生成标准化TXT知识库文档，支持人工校验修正脏数据；
3. **向量知识库层**：BGE中文嵌入模型 + Chroma向量数据库，文档分块、向量化、语义检索；
4. **推理生成层**：Ollama本地大模型，基于检索到的私有参考文档，输出结构化股票分析报告。

## 🧩 核心组件说明
| 组件 | 作用 |
| ---- | ---- |
| Akshare | 开源财经数据SDK，底层基于HTTP爬虫，获取A股行情、基本面、财报数据，输出Pandas DataFrame，作为项目数据源 |
| BGE Embedding | BERT Encoder-only中文嵌入模型，将文本转为固定维度语义向量，用于相似度检索，**只编码不生成文本** |
| Chroma | 轻量级本地向量数据库。持久化存储向量、分片文本与元数据；支持多Collection集合，实现多业务知识库隔离；底层使用HNSW ANN索引做快速语义召回 |
| Ollama | 本地大模型运行管理工具，加载GGUF量化大模型，提供本地HTTP推理服务；底层LLM为Decoder-only Transformer，自回归生成文本 |

## 项目迭代思路与踩坑记录

1. **空 CSV 问题**：早期选股脚本筛选后输出空文件。根因：市场同时满足多重技术条件标的很少；优化：增加日志分步打印筛选条件，增加容错。
2. **爬虫风控报错**：Akshare 批量请求容易被网站断开连接；解决方案：增加重试、请求休眠，架构改为「先输出 TXT 草稿，人工校验后入库」，避免脏数据污染向量库。
3. **大模型推理速度慢**：笔记本 MX550 只有 2G 显存，7B 模型无法加载进显存，Ollama 自动降级 CPU 推理；优化：切换轻量化 3B 量化模型，降低 RAG 召回 topk 数量，精简上下文。
4. **知识库污染**：早期直接爬虫入库，失败会写入空向量分片；优化：引入人工校验环节，向量库重建机制，多业务使用独立 Collection 隔离，防止跨业务误召回。
5. **模型幻觉**：Prompt 约束不足，大模型编造数据；优化：强约束提示词，强制模型只能基于检索到的上下文回答，缺失数据如实说明，固定结构化输出。
##  项目亮点

1. 全链路自动化：选股、数据抓取、文档生成、向量入库、AI 分析完整闭环；
2. 人机协同知识库：机器自动拉原始数据，人工校验清洗，兼顾效率与准确性；
3. 完全本地化部署，无第三方 API 费用，数据本地保存；
4. 工程化设计：支持多业务智能体扩展，Chroma 多 Collection 实现业务隔离；
5. 垂直领域 RAG 落地，解决大模型幻觉问题，所有分析结论可溯源到原始财报与行情数据。
